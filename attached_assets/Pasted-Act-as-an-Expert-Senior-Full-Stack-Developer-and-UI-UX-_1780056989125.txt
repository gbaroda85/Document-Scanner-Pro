### 🚀 Key Features & Detailed Functional Requirements:

1. HOME DASHBOARD & DOC MANAGEMENT
- A clean dashboard showing "Recent Documents" in a grid/list view with thumbnails, titles, and creation dates.
- Search bar to filter documents by name.
- Floating Action Buttons (FAB): "Camera Scan" (opens web cam) and "Upload Image" (drag-and-drop or file picker).
- Ability to create folders, rename, delete, and multi-select documents to merge them into a single PDF.

2. ADVANCED CAMERA & IMAGE CAPTURE
- Access the device's rear/front camera with a live preview overlay.
- "Auto-capture" toggle: Automatically take a picture when a document-like rectangular shape is detected.
- Manual flash/torch toggle (where supported by browser API).

3. SMART CROP & PERSPECTIVE WARPING (The Core Feature)
- Once an image is uploaded/captured, automatically detect the edges of the document using OpenCV.js (Canny Edge Detection + FindContours).
- Display a cropping overlay with 4 interactive corner handles (anchors) and connecting lines so the user can manually adjust the borders.
- Implement a magnifying glass loupe effect near the finger/cursor when dragging a corner for precise adjustment.
- Apply a Perspective Warp algorithm to straighten the cropped area into a perfect, flat rectangle.

4. REAL-TIME CLEAR SCANNER FILTERS
Provide 5 distinct real-time canvas-based image processing filters:
- Original: Unprocessed image.
- Magic Color / Photo: Enhances colors, removes shadows, and boosts brightness.
- Docs (Clear Scanner Signature): High-contrast black and white mode that makes text extremely sharp and clears background noise/shadows.
- Clear: Smoothes out uneven lighting while keeping original colors.
- Grayscale: Pure black, white, and grey tones.
- Include sliders for manual Contrast, Brightness, and Sharpness adjustment.

5. MULTI-PAGE DOCUMENT EDITOR
- Inside a document, users can add more pages, delete specific pages, or reorder them using a drag-and-drop interface.
- Rotate pages (90° clockwise/counter-clockwise).

6. REAL OCR (TEXT EXTRACTION)
- Integrate Tesseract.js to extract text from the current page.
- Show a split-screen or modal: Left side processed image, Right side editable extracted text.
- "Copy to Clipboard" and "Download as .txt" buttons for the OCR text.

7. HIGH-QUALITY EXPORT & SHARING
- Export options: "Download as PDF" or "Download as JPEG/PNG".
- For PDF: Provide quality settings (Low, Medium, Highest) and page size options (A4, Letter, Legal).
- Generate clean, multi-page PDFs where text remains searchable if possible, or images are perfectly aligned without quality loss.
